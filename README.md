## 🌱 Featured Project

### SIIHA — System for the Isolated Illumination × Human Agency

**SIIHA** is an independent AI safety engineering and research project exploring runtime governance for prolonged human-AI interaction.

Rather than modifying the foundation model itself, SIIHA operates as a **model-agnostic governance layer** around model interaction.

The project currently develops along two related tracks:

### Runtime Governance Engineering

The SIIHA Beta runtime extends the earlier deterministic Alpha architecture with:

- Structured governance memory
- Turn-level interaction records
- Continuity-aware trajectory graphs
- Negotiated behavior governance
- Runtime observation windows
- Deterministic failure observation and next-turn controls
- Reversible governance constraints
- LLM-assisted response generation under governance controls

### Longitudinal Trajectory-Drift Research

Alongside the runtime system, SIIHA Beta investigates whether longer-term governance drift can be measured reliably from longitudinal interaction data.

**Beta v0.1** completed a frozen train / validation / held-out test ML experiment using normal-only anomaly detection.

The experiment **did not establish reliable held-out detection of goal-specific semantic governance drift**.

Post-test analysis raised a new measurement question: whether a predominantly turn-centered ML representation is sufficiently aligned with SIIHA's continuity-based trajectory ontology.

**Beta v0.2** was designed as a preregistered follow-up around continuity-valid transitions. However, the required synthetic SG / EA realization set did not pass the predefined semantic validity gate reliably enough to proceed.

**ML training was intentionally not run for v0.2.**

The edge-representation hypothesis therefore remains **untested**.

This negative result and stopped experiment are part of the research outcome rather than hidden implementation failures.

## 🔬 Current Research Questions

I am currently interested in questions such as:

- When does deterministic runtime governance remain sufficient?
- Which governance phenomena require longitudinal rather than recent-turn observation?
- What should the unit of analysis be for longitudinal governance: **node, edge, window, or trajectory**?
- How should semantic governance constructs be translated into observable representations without introducing label leakage?
- How can runtime governance preserve user agency without unnecessarily restricting useful AI assistance?
